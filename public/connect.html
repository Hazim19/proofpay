ProofPay — Connect

Paste sandbox credentials here to switch ProofPay from offline mock mode to the real PayPal sandbox (and, optionally, to a live AI model). Values are stored server-side in a permission-locked local file, take effect immediately, and are never shown again — this page only reports whether each value is configured. Leave a field blank to keep the value already stored.

Setup token
This deployment sets PROOFPAY_SETUP_TOKEN; the token is required to view or change these settings.
PayPal
Sandbox app credentials come from developer.paypal.com → Apps & Credentials → Sandbox.
AI model (optional)
All three AI values are needed for live AI mode; without them the deterministic offline stubs are used.
